# 나대신 구독케어 V3 시제품

일정에 맞춰 AI 구독을 켜고 끄는, 나만의 구독 비서 — **'모두의 창업' 지원용 시제품(MVP) 데모**입니다.

- 데모: https://zergron.github.io/nadacare-v3/
- 빌드 없음: 순수 HTML/CSS/JS 정적 파일 (GitHub Pages에서 그대로 동작)

## 화면
- **홈** — 총 월 구독료, 이번 달 절감 가능 예상액, 평균 사용률, 14개 구독 카드(갱신 D-day·사용률·연결 과제 배지)
- **AI 리포트** — 핵심 지표 2×2, 작업 일정 연동 시뮬레이터(유지/일시정지/해지 → 월·연 절감액과 AI 판단 근거 실시간 계산)
- **작업판** — 과제 상태(진행 중/보류/완료) 토글 시 연결된 구독의 추천 배지 연동
- **내 구독** — 14개 전체 목록, 카테고리 필터·검색·새 구독 추가(데모)
- **기록** — 저장한 결정 타임라인, 홈 요약에 즉시 반영

## 구성
| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (PC 좌측 사업설명 패널 + 스마트폰 목업 / 모바일 풀스크린) |
| `manifest.json`, `sw.js`, `icon-*.png` | PWA(홈 화면 추가)용 |
| `mobile.html` | 로컬 검수용 390px 뷰 래퍼 (배포물 아님, GitHub Pages에서도 접근 가능) |

## 로컬 실행
```
python3 -m http.server 8000
# http://localhost:8000
```

> 화면의 구독·절감액은 체험용 예시 데이터이며 실제 결제는 발생하지 않습니다.
