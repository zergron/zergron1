# 나대신 구독케어 · 2R 시제품

**구독은 한눈에, 필요한 도구는 바로 열고, 갱신은 다음 작업에 맞춰.**
결제내역만으로는 보이지 않는 AI 도구의 크레딧·한도·용도 중복까지 판단하는 구독 점검 비서 — **'모두의 창업' 2라운드 시제품(MVP) 데모**입니다.

> **포지션** 구독의 시작부터 활용·변경·해지·다음 청구 확인까지 관리하는 **한국형 개인 맞춤형 구독케어 에이전트**(구독서비스의 종합생애관리)
> ① 한곳에서 보고 바로 열기 · ② 작업·재개일 연동 판단 · ③ 줄이기 전에 보유 크레딧·기능 먼저 + 한국 공식 할인·번들·대체 요금제 · ④ 공식 경로 안내 ~ 다음 청구 확인
> 범위: **지금 시제품 = 가상 데이터로 판단 규칙 시연** / 제품화 = 직접 입력 웹 MVP·리포트 검증 / 안정화 후 = 제휴·승인 기반 변경·해지 실행

## 데이터 기준
- **데모 기준일 2026-11-20**, 가상 구독 14개 · 월 환산 **210,000원** — 1R 사업계획서 v23 붙임 1(p.10)과 동일
- AI 도구 7개(ChatGPT·Claude·Genspark·Higgsfield·Manus·Vrew·Suno) / 월 131,000원 (전체의 62%)
- **판단 필요 9** (판단 7 + 결제 경과 2), 점검 완료 5/14
- **사용량 표기 원칙(사업계획서 p.10과 100% 일치)**: 비교 가능한 사용률 3개(**ChatGPT 60% · Higgsfield 20% · Vrew 40%**)·크레딧(**Manus 4,000/20,000**)·저장공간(**Google One 68/100GB**)·약정(**SK브로드밴드 약정 만료 D-20**)만 수치로 표시하고, 나머지 8개(Claude·Genspark·쿠팡 와우·Netflix·Suno·YouTube Premium·듀오링고·Spotify Premium)는 **`사용량 미확인`**. 요약 카드 평균은 `비교 가능 3개 평균 40%`
- 문구 원칙: '월 ○○원 절약'·'절감 가능 예상액'·'해지 대행' 미사용, 판단 근거와 다음 청구 확인 중심
- 보유 활용·공식 혜택 안내는 **실제 요금·혜택을 추정·단정하지 않고**, "공식 서비스에서 직접 확인하는 예시 가이드"로만 표기

## 화면
- **홈** — 월 환산 구독료 210,000원(14개), 갱신 임박/경과 확인/판단 필요 타일, `Higgsfield 결제 전 점검` 배너, 필터 `[전체 14] [AI 도구 집중 7] [갱신 임박 6] [경과 확인 2] [판단 필요 9]`, 구독 카드(브랜드 배지·금액·갱신 D-day·사용률/크레딧 게이지·판단 근거·`[서비스 열기 ↗]`/`[구독 점검]`)
  - **요약 타일 = 버튼** — `갱신 임박 6개`·`경과 확인 2개`·`판단 필요 9개` 네모를 누르면 해당 필터로 즉시 전환되고 목록(`#homeResult`)으로 부드럽게 스크롤. 선택된 타일·필터 칩이 함께 강조됩니다.
- **심층 리포트** — 유료 시연 `AI 도구 구독 점검 리포트 (1회 9,900원 · 2R 검증 예정 가격)` ① 용도 중복 ② 크레딧·한도 낭비 ③ **보유 활용 → 공식 혜택·요금제 전환 제안**(`먼저` 보유 크레딧·기능 → `그다음` 한국 공식 할인·번들·대체 요금제) ④ 다음 작업일 기준 재점검일 + **작업 일정 연동 시뮬레이터** — 재개일(다음 작업일)만 바꿔도 추천(`유지 검토` ↔ `하향·중단 검토`)과 판단 근거·처리 시점·다음 청구 문구가 **자동 전환**(기준: 갱신일 +7일 안 재개 = 유지, 그보다 늦으면 이번 결제 불필요). 최종 결정은 아래에서 저장(`내 결정 기록에 저장`, 고르지 않으면 추천대로), `예시 다시 체험`은 가상 재개일만 초기값으로 되돌리고 저장한 결정 기록은 보존
- **작업판** — 과제 상태(진행 중/보류/완료) 토글 시 연결 구독의 판단 배지 연동
- **내 구독** — 14개 목록, 카테고리·검색, 새 구독 추가(데모)
- **기록** — 저장한 결정 + 3단계 진행(① 판단 저장 → ② 변경 처리 → ③ 다음 청구 확인), 공식 페이지 링크
- **구독 점검 모달** — 날짜 입력(재개일) 변경 시 **추천 배지·근거가 실시간 자동 전환**, 판단 근거 3줄, **`💡 줄이기 전에 먼저 확인`**(판단 근거 바로 아래 · 보유 기능·크레딧 먼저 쓰기 / 한국형 공식 할인·번들·대체 요금제 · 가상 예시 표기), 4단계 블록(`[공식 변경·해지 페이지 열기 ↗]` + 변경 처리/다음 청구 확인 토글), 비밀번호·카드번호 미수집 안내. 연결 작업이 `완료`뿐인 구독(Netflix 등)에서 `진행 중인 undefined 작업`이 나오지 않도록 문구 분기
- **상태 저장(localStorage)** — 저장한 결정(판단·재개일)·변경 처리/다음 청구 확인 체크·작업판 상태·추가한 구독·시뮬레이터 재개일을 브라우저에 저장해 **새로고침 후에도 기록 탭과 홈 배지가 그대로 유지**됩니다(`데모 데이터 초기화` 시 함께 삭제)
- **화면 배율** — 상단 헤더 `🔍 100%` 버튼 → `70% · 100% · 120% · 150%` 선택(기본 100%). 앱 본문이 CSS `zoom`으로 다시 배치되어 확대해도 가로 스크롤·텍스트 잘림이 없고, 선택값은 localStorage에 남아 새로고침·탭 전환 후에도 유지(데모 초기화 시 100% 복귀)
- **모바일 뒤로가기(Back)** — `history.pushState` + `popstate` 연동. 구독 점검 모달·앱 설치 안내·새 구독 모달·화면 배율 팝오버가 열려 있을 때 스마트폰 뒤로가기를 누르면 시제품을 벗어나지 않고 **그 모달/팝오버만 닫히며 현재 화면에 그대로 머뭄**(URL 유지). 홈이 아닌 탭(심층 리포트·작업판·내 구독·기록)도 히스토리 한 칸을 차지해 **뒤로가기 시 홈(이전 탭)으로 복귀**하고, × 버튼·배경 클릭으로 직접 닫을 때는 쌓은 칸을 `history.back()`으로 정리해 뒤로가기가 꼬이지 않음. 홈에서 모달이 없을 때는 브라우저 기본 뒤로가기 그대로 동작

## 배포 구조
- `main` : 소스 기준 브랜치
- `gh-pages` : **실제 게시되는 브랜치** (GitHub Pages → Deploy from a branch → gh-pages / root)
- 사이트를 갱신하려면 `main` 변경 후 `gh-pages`에도 반영해야 합니다.

## 로컬 실행
```
python3 -m http.server 8000
# http://localhost:8000
```

> 화면의 14개 구독은 가상 데이터이며 실제 결제·변경은 발생하지 않습니다. 판단은 규칙 기반 시연이고, 나대신은 비밀번호·카드번호를 받지 않습니다.
