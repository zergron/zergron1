# 나대신 구독케어 · 공개 체험판 (v24)

**구독은 한눈에, 필요한 도구는 바로 열고, 갱신은 다음 작업에 맞춰.**
종합현황 · 이용 포털 · 계약·비용 최적화 · 혜택 활용의 네 가지 기능을 갖춘 **한국형 개인 맞춤형 구독케어 에이전트**의 공개 체험판입니다. 내 구독을 직접 입력하거나 **샘플 이미지**, 가상 결제 알림으로 등록하는 것이 네 가지 기능을 쓰기 위한 첫 단계입니다.

## 공개 체험판에서 할 수 있는 것

### 첫 화면 (홈)
- 상단 네이비 헤더의 **`서비스특징` 버튼** → 네 가지 특징을 모달 팝업으로 표시(각 카드에서 해당 화면으로 이동, `✕`·휴대폰 뒤로가기로 닫힘). 버튼 라벨은 띄어쓰기 없이 `서비스특징`이고, 360px 폭에서도 부제 `구독 하나에 특화된 전문 서비스`가 잘리지 않고 버튼과 겹치지 않습니다(v23 수정)
- **월 환산 구독료 210,000원 · 14개 구독** + **3개 요약 타일**(갱신 임박 / 경과 확인 / 판단 필요) + 평균 사용률·내 결정 진행 바만 남긴 컴팩트 요약 카드
- 그 아래 곧바로 **[다음 행동] 카드**(Higgsfield 결제 전 점검)로 진입, 기본 배율 **120%** (v24: 홈의 `이미지로 구독 등록` 배너 제거 — 등록 입구는 내 구독 탭 상단에만 둡니다)
- **[다음 행동] 바로 아래 `먼저 쓸 혜택` 카드 1개** — 잔여 크레딧이 있는 구독(기본：Manus 16,000원 · 만료 12/27)을 다음 작업(「나대신 2R 제품 개발」)과 연결해 보여 주고, 누르면 그 구독의 혜택·점검 화면으로 이동(네 번째 기능 '혜택 활용'을 홈에서 바로 체험)
- 등록·체험 버튼은 홈에서 **내 구독 탭 상단에 위치** (아래 참조)

### 내 구독 탭 상단 · 등록·체험
- **직접 입력** — 서비스명·금액·다음 결제일 3가지로 내 구독 1건 등록
- **샘플 이미지로 등록** — 가상 결제문자·렌탈 청구서 이미지에서 항목을 확인·수정해 등록
- **가상 알림 불러오기** — 문자·메일 샘플 3종에서 찾은 구독을 확인해 등록
- `실제 계정·결제 연결 없이 이 브라우저에만 저장됩니다` 안내를 함께 배치

### 등록 (네 가지 기능의 첫 단계)
- **직접 입력**: 서비스명·금액·다음 결제일 3가지만으로 시작, 모르는 값은 `미확인`. 결제 주기(월/연)·채널(웹/App Store/Google Play)·정상가·할인 종료일은 펼쳐서 보완
- **샘플 이미지로 등록**: 실제 업로드·로그인 없이 직접 그린 **가상 샘플 2종**(`샘플 시연` 배지)
  - AI·OTT 결제문자: 서비스명·금액·**이미 결제된 날짜**를 채우고, 문서에 없는 **다음 결제일은 `미확인`**
  - 인터넷·정수기 렌탈 청구서: 업체명·월 요금·**월 청구 예정일(매월 25일)**·**약정/의무사용기간 종료일(2027-06-30)**을 각각 표시하고, 문서에 없는 **실제 납부(이미 결제된 날짜)는 `미확인`**으로 둡니다(납부일을 임의로 채우지 않음)
  - **`프로젝트에 추가`** — 등록 확인·수정 화면과 등록 완료 화면에서 진행 중인 프로젝트를 골라 작업판과 바로 연결
  - 확인·등록 전에는 목록·합계 미반영, 같은 샘플 재등록 시 중복 집계 차단
  - 등록 결과 화면의 **`이미지 샘플만 초기화`** — 이미지로 등록한 항목만 지우고 가상 알림 불러오기 등록분·Higgsfield 결정·즐겨찾기·프로젝트 기록·직접 입력은 그대로 유지
- **가상 결제 알림 불러오기**: 문자·메일 중복 병합 → 확인 필요 보류 → 일회성 제외 → 선택 항목 등록(14개 210,000원 → 15개 219,900원)
- **월 환산액과 실제 다음 청구액을 구분**, 같은 서비스의 웹/앱스토어 계약은 별도 건으로 표시(채널 배지)
- 29~31일 결제는 **말일 기준 변동 가능 · 확인 필요**로 표시(임의 보정 없음)

### 판단과 기록
- **유지 · 하향 · 중단 · 판단 보류** 4가지 추천. 사용량·다음 작업일이 부족하면 **판단 보류**
- **7일 기준은 참고 규칙**으로 표시. 재개일만 바꿔도 추천·이유·금액이 즉시 전환. **재개일을 바꾼 뒤 `내 결정`을 골라도 입력한 재개일과 바뀐 추천이 그대로 유지**되고, 저장·새로고침 후에도 날짜·추천·내 결정·판단 근거가 일치
- **추천 / 내 결정 / 직접 처리 / 청구 확인** 4가지 상태를 별도 관리. 결정을 고르지 않으면 저장되지 않음(추천 자동 확정 없음)
- **이미 낸 금액 · 다음에 피할 수 있는 청구 · 실제로 확인한 청구**를 분리. 청구 확인 전에는 `청구 없음`이 아니라 **`다음 청구 확인 예정`**
- 결제 채널별 공식 관리 경로(웹/Apple/Google Play)로 연결, 채널 미확인 시 그 자리에서 선택
- 사용자 직접 체크 기록과 시스템 자동 확인(향후 구현 계획)을 명확히 구분

### 나머지 기능
- **이용 포털**: 즐겨찾기(★)와 프로젝트별 필터, 카드의 공식 경로를 **디지털 구독(AI·OTT)** = `공식 서비스 열기 ↗`, **통신·렌탈** = `공식 계약 관리 ↗`로 구분하고 `구독 점검`과 분리, 여러 작업이 함께 쓰는 도구 표시
- **혜택 활용**: 사용량·잔여 크레딧·만료일을 구분하고 보유 혜택을 먼저 사용. 부족할 때만 공식 할인·번들·대체 요금제를 **출처·적용 조건**과 함께 비교. 만료·이월·환불이 불명확하면 `확인 필요`, 크레딧 사용 전 환불 조건 확인 안내
- **작업판**: 과제 상태(진행 중/보류/완료)가 연결 구독 판단에 반영. 한 작업이 보류돼도 다른 진행 중 작업에 필요하면 유지
- **심층 리포트**: 1회 9,900원 · 2R 검증 예정 가격(체험판 실제 결제 없음), 작성 목표 16분 이하

## 데이터·저장 원칙
- 데모 기준일 2026-11-20, 가상 구독 14개 · 월 환산 **210,000원** (사업계획서 붙임 1과 동일)
- 사용률 표시: ChatGPT 60% · Higgsfield 20% · Vrew 40% / Manus 크레딧 4,000/20,000 · Google One 68/100GB · SKB 약정 D-20, 나머지는 `사용량 미확인`
- **샘플 / 불러온 샘플 / 이미지 샘플 / 직접 입력을 분리 저장**. `샘플 초기화`는 샘플·불러온 샘플·이미지 샘플을 되돌리고 **직접 입력과 그 결정 기록은 유지**. 이미지 샘플은 `이미지 샘플만 초기화`로만 따로 지울 수 있습니다(불러온 샘플·결정·즐겨찾기·프로젝트 기록 보존)
- 직접 입력 건은 개별 삭제, PC 소개의 `내 입력 전체 삭제`로 일괄 삭제
- 입력 내용은 브라우저(localStorage)에만 저장, 외부 서버 전송 없음. 비밀번호·카드번호·실제 영수증 업로드 없음
- 이미지 샘플의 `공식 서비스 열기`·`공식 계약 관리`는 가상 서비스이므로 문서용 주소(`example.com`)로 연결됩니다
- 금지 표현(`월 ○○원 절약`, `절감 가능 예상금액`, `해지 대행`) 미사용
