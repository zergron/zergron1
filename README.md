# 나대신 구독케어 · 2R 시제품

**구독은 한눈에, 필요한 도구는 바로 열고, 갱신은 다음 작업에 맞춰.**
결제내역만으로는 보이지 않는 AI 도구의 크레딧·한도·용도 중복까지 판단하는 구독 점검 비서 — **'모두의 창업' 2라운드 시제품(MVP) 데모**입니다.

- 데모(PC·모바일): **https://zergron.github.io/zergron1/**
- PC 1280px 검수: https://zergron.github.io/zergron1/pc.html
- 모바일 390px 검수: https://zergron.github.io/zergron1/mobile.html
- 빌드 없음: 순수 HTML/CSS/JS 정적 파일 (GitHub Pages에서 그대로 동작)

## 데이터 기준
- **데모 기준일 2026-11-20**, 가상 구독 14개 · 월 환산 **210,000원** — 1R 사업계획서 v23 붙임 1(p.10)과 동일
- AI 도구 7개(ChatGPT·Claude·Genspark·Higgsfield·Manus·Vrew·Suno) / 월 131,000원 (전체의 62%)
- 갱신 임박 6 · 결제 경과 2 · 판단 필요 8 (판단 6 + 경과 2)
- 문구 원칙: '월 ○○원 절약'·'절감 가능 예상액'·'해지 대행' 미사용, 판단 근거와 다음 청구 확인 중심

## 화면
- **홈** — 월 환산 구독료 210,000원(14개), 갱신 임박/경과 확인/판단 필요 타일, `Higgsfield 결제 전 점검` 배너, 필터 `[전체 14] [AI 도구 집중 7] [갱신 임박 6] [판단 필요 8]`, 구독 카드(브랜드 배지·금액·갱신 D-day·사용률/크레딧 게이지·판단 근거·`[서비스 열기 ↗]`/`[구독 점검]`)
- **심층 리포트** — 유료 상품 시연 `AI 도구 구독 점검 리포트 (1회 9,900원 샘플)` ① 용도 중복 ② 크레딧·한도 낭비 ③ 요금제 전환 제안 ④ 다음 작업일 기준 재점검일 + **작업 일정 연동 시뮬레이터**(진행 과제 있음(유지) / 요금제 하향·변경 / 갱신 중단 검토, 재개·재점검일 입력 시 판단·처리 시점·다음 청구 문구 즉시 변경)
- **작업판** — 과제 상태(진행 중/보류/완료) 토글 시 연결 구독의 판단 배지 연동
- **내 구독** — 14개 목록, 카테고리·검색, 새 구독 추가(데모)
- **기록** — 저장한 결정 + 3단계 진행(① 판단 저장 → ② 변경 처리 → ③ 다음 청구 확인), 공식 페이지 링크
- **구독 점검 모달** — 판단 근거 3줄, 재개·재점검일, 4단계 블록(`[공식 변경·해지 페이지 열기 ↗]` + 변경 처리/다음 청구 확인 토글), 비밀번호·카드번호 미수집 안내

## 구성
| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (PC 좌측 사업설명 패널 + 스마트폰 목업 / 모바일 풀스크린) |
| `pc.html` | PC 1280×900 뷰 검수용 래퍼 |
| `mobile.html` | 모바일 390px 뷰 검수용 래퍼 |
| `manifest.json`, `sw.js`, `icon-*.png` | PWA(홈 화면 추가)용 |

## 배포 구조
- `main` : 소스 기준 브랜치
- `gh-pages` : **실제 게시되는 브랜치** (GitHub Pages → Deploy from a branch → gh-pages / root)
- 사이트를 갱신하려면 `main` 변경 후 `gh-pages`에도 반영해야 합니다.

## 로컬 실행
```
python3 -m http.server 8000
# http://localhost:8000
```

> 화면의 14개 구독은 가상 데이터이며 실제 결제·변경은 발생하지 않습니다. 판단은 규칙 기반 시연이고, 나대신은 비밀번호·카드번호를 받지 않습니다.
